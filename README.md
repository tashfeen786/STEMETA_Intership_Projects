# STEMETA_Intership_Projects 🚀

This repository contains a collection of machine learning and data science projects developed during my internship at **STEMETA**. Each project addresses a real-world problem, applying data analysis, feature engineering, model training, and evaluation techniques. The primary focus is on improving prediction performance, handling imbalanced data, and interpreting results with clarity.

---

## 📁 Projects Included

### 1. 🧠 Breast Cancer Detection

A classification model using supervised learning to predict whether a tumor is benign or malignant based on diagnostic features.

### 2. 💳 Credit Card Fraud Detection

This project tackles the challenge of detecting fraudulent transactions using imbalanced data handling techniques like SMOTE, and classification models such as Random Forest and Logistic Regression.

### 3. 💡 Health Indicator Analysis

Explores general health data to identify indicators related to disease prediction, patient profiling, and healthcare decision support using EDA and ML models.

### 4. ❤️ Heart Failure Prediction

A machine learning approach to predict the likelihood of heart failure in patients based on clinical records, focusing on precision and recall for life-saving decision-making.

### 5. 🧑‍💼 IMB HR Analytics - Employee Attrition

Analyzes HR data to predict employee attrition using classification models, and derives insights into factors influencing employee turnover.

### 6. 📧 Spam Email Detection

A Natural Language Processing (NLP) project that classifies emails as spam or ham using TF-IDF and Multinomial Naive Bayes.

### 7. 📱 Telco Customer Churn Prediction

This project aims to predict customer churn based on demographic, account, and service usage data, leveraging logistic regression and decision trees.

### 8. 🚢 Titanic API (Survival Prediction)

An end-to-end machine learning model to predict passenger survival using classic Titanic dataset, with deployment using Flask REST API.

### 9. 📊 Handling Imbalanced Data in Customer Churn

Focused on resolving class imbalance in the Telco Churn dataset using techniques such as SMOTE, Random Under/Over Sampling, and evaluating their impact on model performance.
